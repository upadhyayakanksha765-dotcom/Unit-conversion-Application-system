# Unit-conversion-Application-system
A unit conversion application is a python based program designed to convert values from one unit to another quickly and accurately. 
Unit Conversion Application
A menu-driven python application that converts values between different unit such has length, weight , Temprature ,Area , Volume ,Time,speed ,digital, storage , data rate presure energy, power and angle.

## About the project
The unit conversion Application to help easy for beginners . Which user can select a category and then solve a properly and performing different type of unit conversion.
## Features
-  Length conversion -Convert between meters, kilometers, and centimeters.
• Weight:-  Convert kilograms, grams, milligrams, and pounds.
• Temperature: - Support for Celsius, Fahrenheit, and Kelvin conversions.
• Time: - Conversion between hours, minutes, and seconds.
• Area: - Convert square meters, square centimeters, and square kilometers.
• Volume: - Convert liters, milliliters, and cubic meters.
• Speed: - Support for km/h, m/s, and mph conversions.
• Digital Storage: - Binary unit conversions (Bytes, KB, MB, GB).
• Continuous Execution:-  Integrated loop allows running consecutive conversions without
